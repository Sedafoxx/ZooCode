# 🦁 ZooCode

Zoo's personal tooling workshop — a collection of scripts, templates, and reusable utilities for building DIY coding projects.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run scaffold` | Scaffold a new project from a template |
| `npm run analyze`  | Quick code analysis on a target directory |
| `npm run test`     | Run all tests |
| `npm run lint`     | Lint all source files |

## Structure

```
ZooCode/
├── scripts/     CLI tools and automations
├── lib/         Reusable helper modules
├── templates/   Project scaffolding templates
├── docs/        Knowledge base & project notes
└── tests/       Tests for tools and libs
```
